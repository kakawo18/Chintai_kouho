# 物件メモ — 自動入力の中継サーバー

物件ページの URL を渡すと、ページを読んで項目を抜き出して返す小さなサーバーです。
Cloudflare Workers の無料枠で動き、**クレジットカードの登録は不要**です。

## なぜ必要か

アプリだけでは以下ができないためです。

| できないこと | 理由 |
|---|---|
| API キーを安全に持つ | アプリはブラウザで動くので、キーを入れると利用者全員に見えてしまう |
| 物件ページを読む | ブラウザは別サイトの中身を読めない（CORS の制約） |
| 誰かと共有したときに相手にも使わせる | キーを渡さずに使ってもらうには、間に何かを挟むしかない |

キーはこのサーバーの環境変数にだけ置かれ、**アプリにも GitHub にも出ません。**

---

## セットアップ

### 1. Cloudflare のアカウントを作る

[dash.cloudflare.com](https://dash.cloudflare.com) で無料アカウントを作ります。

### 2. 合言葉を決める

このサーバーを勝手に使われないようにするための文字列です。推測されない長さにしてください。
手元で生成する場合：

```bash
node -e "console.log(require('crypto').randomBytes(16).toString('hex'))"
```

### 3. 公開元を設定する

`wrangler.toml` の `ALLOWED_ORIGIN` を、アプリを配信している URL に合わせます。

```toml
ALLOWED_ORIGIN = "https://kakawo18.github.io"
```

`KIMI_BASE_URL` は契約したプラットフォームに合わせてください。

- platform.moonshot.ai の場合 → `https://api.moonshot.ai/v1`
- platform.kimi.ai の場合 → `https://api.kimi.ai/v1`

> どちらが正しいかは Kimi のコンソールに表示されているベースURLで確認してください。
> 間違えると `model_failed` になります。

### 4. デプロイする

```bash
cd worker
npx wrangler login          # ブラウザが開くので許可する
npx wrangler secret put KIMI_API_KEY      # Kimi の API キーを貼る
npx wrangler secret put APP_PASSPHRASE    # 手順2で決めた合言葉を貼る
npx wrangler deploy
```

最後に `https://chintai-kouho-extract.<あなた>.workers.dev` のような URL が表示されます。

> ⚠️ **`KIMI_API_KEY` と `APP_PASSPHRASE` は必ず `wrangler secret put` で登録してください。**
> `wrangler.toml` に書くとリポジトリに入ってしまいます。

### 5. アプリ側に登録する

アプリの **⋮ メニュー > 自動入力** に、手順4の URL と手順2の合言葉を入れて保存します。
誰かと共有している場合は、相手にも同じ2つを伝えれば相手の端末でも使えます。
**Kimi のキーを渡す必要はありません。**

---

## 使い方

物件の追加画面の上部に入力欄が出ます。

1. 物件ページの **URL を貼って「読み取る」** → 項目が自動で埋まります
2. 取得できないページだった場合は、その旨が表示されるので **ページの文字をコピーして貼り、もう一度「読み取る」**

**読み取った内容は保存されません。** フォームに入るだけなので、必ず目で確認してから保存してください。
すでに手で入力した欄は上書きしません。

---

## 制約

- **JavaScript で描画するページは読み取れません。** ページ側が中身を JS で組み立てている場合、
  取得できるのは空の枠だけです。テキストを貼る方法に切り替えてください
- **サイト側にブロックされる場合があります。** 物件サイトはデータセンターからのアクセスを
  弾くことがあります。この場合もテキスト貼り付けなら通ります
- 抽出結果は**必ず正しいとは限りません**。特に敷金・礼金の「ヶ月／円」の解釈や、
  複数の部屋が載っているページでは取り違えが起こり得ます。保存前の確認が前提の機能です
- **住所の番地は補いません。**物件サイトは番地を伏せていることが多いため、
  書かれているところまでを返し、あわせて「どこまで書かれていたか」（`addressLevel`）を返します。
  番地が無い場合、アプリ側はその物件を「位置が未確定」として扱い、地図に範囲の円で表示します
- 読み込むページ本文は6万文字で打ち切ります（費用と時間の制限）

## 使うモデルを変える

決まった項目を抜き出すだけの仕事なので、最上位のモデルは要りません。
**既定は `kimi-k2.6`** です。`wrangler.toml` の `KIMI_MODEL` を書き換えて
`npx wrangler deploy` し直すか、Cloudflare の画面（**Settings > Variables**）で変えられます。
**コードを触る必要はありません。**

```toml
KIMI_MODEL = "kimi-k2.6"
```

| モデル | 入力 | 出力 | 使いどころ |
|---|---|---|---|
| **`kimi-k2.6`** | $0.95 | $4 | **既定。**これで足ります |
| `kimi-k3` | $3 | $15 | 最上位。読み取りの精度が足りないときだけ |

（100万トークンあたり／国際課金 `api.moonshot.ai` の場合）

### 思考は切ってあります

`kimi-k2.6` は考えてから答えるモデルです。**考える過程のトークンも `max_tokens` に含まれ、
そのぶん出力として課金されます。**決まった項目を抜き出すだけの仕事に深い思考は要らないので、
`KIMI_THINKING = "disabled"` で切ってあります。

切らないと2つ困ることが起きます。

1. **答えが途中で切れる。**考えるだけで枠を使い切り、JSON が尻切れで返る
2. **安くならない。**思考ぶんの出力が課金され、上位モデルと変わらない額になる

このモデルには思考が要る、と分かった場合は `KIMI_THINKING` を `disabled` 以外にしてください。
指定そのものを送らなくなり、API の既定に従います。その場合は `KIMI_MAX_TOKENS` を
16000 以上にしておいてください（Kimi の推奨値です）。

> ⚠️ **`kimi-k2.5` は選ばないでください。**新規登録では利用できなくなっており、
> 2026年8月31日でプラットフォームごと終了する予定です。安いという理由で選ぶと、
> ほどなく動かなくなります。
>
> `kimi-k2` 系（2.5 を除く旧シリーズ）は 2026年5月25日に提供終了済みです。

モデル名を間違えると `抽出に失敗しました（404）` のように出ます。
アプリ側にも「`KIMI_MODEL` を確認してください」と表示されます。

### うまくいかないとき

失敗したときは、**番号のあとに `［...］` で理由が出ます。**そこを見て切り分けてください。

| 出るもの | 意味 | 対処 |
|---|---|---|
| `答えが途中で切れました（max_tokens 不足）` | 考える過程で枠を使い切った | `KIMI_THINKING` が `disabled` か確認。それでも出るなら `KIMI_MAX_TOKENS` を増やす |
| `本文が空です（finish_reason: length）` | 同上（答えが1文字も出なかった場合） | 同上 |
| `APIがエラーを返しました: ...` | Kimi 側が拒否した | 続く文にキー切れ・残高・モデル名などの理由が出ます |
| `choices が空です: ...` | 応答の形が想定と違う | `KIMI_BASE_URL` が正しいか確認 |
| `応答がJSONではありません: ...` | 別のものが返ってきた | `KIMI_BASE_URL` の宛先違いが多い |
| `JSONとして読めません: ...` | 中身が壊れている | 続く文に実際の中身が出ます |

> モデルによって答えの返し方が違います（文字列／配列／` ```json ` で囲む／
> 説明文を添える／考える過程の側に入れる）。中継サーバーはこの5通りを
> すべて受け取れるようにしてあるので、モデルを変えても読めなくなることはありません。

## 費用

`kimi-k2.6` は入力 $0.95 / 出力 $4（100万トークンあたり）です。
物件ページ1件あたりおおよそ2万トークンなので、**1件あたり日本円で3円前後**、
30件登録しても100円程度の見込みです。

> 以前の既定だった `kimi-k3`（入力 $3 / 出力 $15）では1件10円前後でした。
> **`kimi-k2.6` に変えたことで、おおよそ1/3になります。**

Cloudflare Workers は無料枠（1日10万リクエスト）に十分収まります。

## 動作確認済みの内容

Cloudflare の実行環境（workerd）で以下を実際に通しています。

- CORS のプリフライトが設定した配信元を返すこと
- 合言葉なし・合言葉違いを 401 で拒否すること
- `file://` など http(s) 以外の URL を拒否すること
- ページ取得 → script/style を除去した本文抽出 → Kimi へ既定のモデルと
  strict な JSON スキーマで送信 → 結果を返すこと
- `KIMI_MODEL` を指定しなければ `kimi-k2.6` が、指定すればその名前が送られること
- モデルの答えを5通りの形（文字列／配列／` ```json ` 囲み／説明文つき／
  考える過程の側）で受け取れること
- 失敗する4通り（打ち切り／choices なし／JSON でない／API のエラー）で、
  番号だけでなく理由が返ること
- そのスキーマに `addressLevel` が含まれ、`required` にも入っていること
  （strict モードでは全項目が `required` に必要）
- 番地を補わない指示と、粒度の判定例が指示文に含まれていること
- 取得失敗・中身が薄いページを、テキスト貼り付けへ誘導する応答にすること
